# 🧠 Resumo Rápido

## 🔹 Checked Exception

São exceções que o Java obriga tratar durante a compilação.

---

## 🔹 Unchecked Exception

São exceções que não precisam ser tratadas obrigatoriamente.

---

## 🔹 Exception Personalizada

Exceções criadas pelo próprio desenvolvedor para representar regras específicas do sistema.

---

## 🔹 try/catch

Usado para tentar executar um código e tratar possíveis erros.

---

## 🔹 finally

Bloco executado independentemente de ocorrer erro ou não.

---

## 🔹 throw

Usado para lançar manualmente uma exceção.

---

## 🔹 throws

Usado para informar que um método pode lançar uma exceção.
